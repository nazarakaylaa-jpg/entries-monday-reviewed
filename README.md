## The entry

`main.py` writes one funny one-line review of my Monday to `/output/entry.txt` (1–200 characters, one line):

> Monday, one star: my alarm snoozed itself, my coffee tasted like regret, and my 9 a.m. was a meeting to plan a meeting about the meeting.

## Run

```sh
python3 main.py
```

Verifies the gate at runtime (1–200 characters, single non-blank line) and writes the entry deterministically — repeated runs produce byte-identical output.
